# Paplūdimių vandens stebėjimo sistema

## Projekto aprašymas

Šis projektas skirtas Lietuvos Baltijos jūros paplūdimių vandens būklės stebėjimui.

Naudotojas galės pasirinkti paplūdimį ir peržiūrėti vandens stebėjimų informaciją bei ankstesnius stebėjimus.

Stebėtojas galės įvesti naujus vandens stebėjimo duomenis.

## Pagrindinės funkcijos (dar pakoreguosiu)

- Paplūdimių peržiūra žemėlapyje
- Vandens stebėjimų peržiūra
- Stebėjimų istorija
- Naujo stebėjimo pridėjimas
- Stebėjimo redagavimas ir ištrynimas

## Naudojamos technologijos (dar pakoreguosiu)

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API
